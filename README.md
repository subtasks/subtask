# 🚀 Subtasks – Gilded Digital Presence

This repository contains the frontend codebase for **Subtasks**, a digital solutions company focused on **web development, software solutions, automation, and digital transformation**.

The project is built using modern web technologies with a focus on **performance, scalability, clean UI, and production-ready deployment**.

## 🧩 Project Overview

This project powers Subtasks’ official digital presence and includes:

- Premium, minimal UI
- Fully responsive layouts
- Smooth navigation and scroll handling
- Legal & compliance pages (Privacy, Terms, Cookies)
- Production-ready
- JSON-driven content for easy updates

---

## 🧱 Architecture Highlights

- Component-driven design
- JSON-driven static content (policies, footer, metadata)
- SPA-safe routing with refresh protection
- Clean separation of UI, data, and routing
- Ready for backend / API integration
- Responsive and accessible design
- Production-ready Git & deployment workflow

## 🔁 Branch & Deployment Strategy

- Development and staging work is done on feature or custom branches 
- Production deployments are handled via **Vercel**
- Branch-based deployments allow safe testing before release

---

## 🔀 Routing & Scroll Behavior

The app includes:
- Automatic scroll-to-top on page navigation
- Proper handling of hash (`#section`) links with navbar offset
- SPA-safe routing (no 404s on refresh)

## 🧪 Local Development

### Requirements
- **Node.js**
- **npm**

> Recommended: install Node using **nvm**  
> https://github.com/nvm-sh/nvm#installing-and-updating

---

### Run the project locally

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev

---

## 🏗️ Production Build

npm run build

Build output (dist/) is generated automatically and is not committed to Git.

```
